# ⚡ QuickLink — AI Photo Scan & Price Comparison Hub

> A modern, responsive web application for instant access to India's top shopping, quick grocery delivery, and food apps with **AI-powered Photo Scan & Live Price Comparison**.

🌐 **Live Website**: [https://noorfatma160207-dotcom.github.io/coding/](https://noorfatma160207-dotcom.github.io/coding/)

---

## ✨ Features

- 📸 **AI Photo Scanner & Price Compare**:
  - Drag-and-drop or upload any product photo.
  - Live camera snapshot mode directly from mobile or desktop.
  - Client-side Computer Vision powered by **TensorFlow.js + MobileNet** (100% private, zero API key required).
  - Multi-platform live search & price comparison across **Amazon India**, **Flipkart**, **Myntra**, **Meesho**, **Blinkit**, and **Google Shopping**.
- 🔍 **Real-Time App Search**: Instant keyboard search (`/`) across all major platforms.
- 🌙 **Dark & Light Mode**: Seamless theme switching with saved preferences.
- ❤️ **Favorites System**: Pin and bookmark your most frequently used apps.
- 📱 **100% Responsive Design**: Optimized for smartphones, tablets, and desktop displays.
